# 특수교육 누가기록 시스템

특수교육 교사를 위한 누가기록 자동화 시스템입니다.
키워드를 선택하면 자동으로 누가기록 문장이 생성됩니다.

## 주요 기능

- **학생 관리**: 학생 등록, 조회, 삭제
- **누가기록 자동화**: 키워드 선택 → 문장 자동 생성
- **기록 저장**: 날짜별, 영역별로 기록 저장
- **기록 조회**: 저장된 기록 목록 확인

## 지원 영역 및 키워드

| 영역 | 키워드 예시 |
|------|------------|
| 학습 | 집중, 향상, 참여, 이해, 완수, 어려움, 산만 |
| 행동 | 차분, 규칙준수, 자기조절, 개선, 충동, 공격, 이탈 |
| 사회성 | 협력, 대화, 배려, 인사, 갈등, 위축 |
| 자립생활 | 정리정돈, 식사, 위생, 이동, 착탈의, 도움필요 |
| 의사소통 | 표현, 이해, AAC, 발화, 어려움표현 |

## 실행 방법

### 1. 의존성 설치
```bash
cd special-ed-records
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

### 3. 웹 브라우저에서 접속
브라우저를 열고 아래 주소로 접속하세요:
```
http://localhost:3000
```

## 사용 방법

1. **학생 등록**: 왼쪽 패널에서 "추가" 버튼을 클릭하여 학생 정보 입력
2. **학생 선택**: 기록할 학생 클릭
3. **날짜 선택**: 기록 날짜 설정 (기본: 오늘 날짜)
4. **영역 선택**: 학습, 행동, 사회성 등 영역 선택
5. **키워드 선택**: 해당 영역의 키워드 클릭 (복수 선택 가능)
6. **문장 생성**: "누가기록 문장 생성" 버튼 클릭
7. **수정 및 저장**: 생성된 문장을 필요시 수정 후 "기록 저장" 클릭

## 데이터 저장 위치

모든 데이터는 `data/` 폴더에 JSON 파일로 저장됩니다:
- `data/students.json`: 학생 정보
- `data/records.json`: 누가기록
